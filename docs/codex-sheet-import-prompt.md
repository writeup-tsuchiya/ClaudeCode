# Codex へ渡す指示文（毎朝9時のスプレッドシート追記ルーティン）

Claude 側からは Google スプレッドシートのセルを書き換える手段が無い（コネクタが存在しない）。
そこで Claude は Drive にCSVを置くところまでを担当し、シートへの追記は Codex が行う。

```
Claude（朝8時）→ Drive「ヒロシ送信キュー」にCSVを作成
                        ↓
Codex（朝9時）  → CSVを読んで「送信mailログ」へ追記 → CSVを「処理済み」へ移動
```

以下をそのまま Codex に貼る。

---

## 貼り付ける指示文

あなたに、毎朝9時（日本時間）に自動で走るルーティンを1つ作ってほしいです。
まずルーティンを作成し、そのあと下記の処理を毎日実行してください。

### ルーティンの設定

- 名前：`ヒロシ送信ログ→スプレッドシート追記`
- スケジュール：**毎日 9:00（日本時間）**
- 内容：下記「毎日の処理」を実行する

### 毎日の処理

**1. Drive のキューフォルダを見る**

フォルダID `1tlwhtOwSh8J6_N8xaPNdNoUm3BRyXUfq`（名前は「ヒロシ送信キュー」）の直下にある
`.csv` ファイルを列挙する。`送信mailログ_追加_YYYY-MM-DD.csv` という名前で置かれている。

ファイルが1つも無ければ、何もせず静かに終了する（Slack投稿も不要）。

**2. 追記先のシートを開く**

- スプレッドシートID：`1QML2V0qLX1tlfse-ONXW56-ifu377pGq9p20WNOsNII`（商談情報統合ヨミ表）
- シート名：**送信mailログ**（gid=79710098）
- **他のタブ（「ヨミ表転記マスターデータ（触らない）」「ヨミ表転記データ」）には一切触れない。**
- **既存の行も書き換えない。追記のみ。**

**3. CSVの中身をそのまま追記する**

CSVはヘッダー行なし、1行14列で、シートのA〜N列と同じ並びになっている。

| 列 | 内容 |
|---|---|
| A | 作成日（YYYY/MM/DD） |
| B | 送信状況（`送信済` / `バウンス` / `保留`） |
| C | 送信元（ai.firststep2026@gmail.com） |
| D | 送信先 |
| E | 会社名 |
| F | 宛名 |
| G | 件名 |
| H | 本文（改行を含む。**セル内改行として保持すること**） |
| I | TimeRex URL |
| J | 提案資料URL |
| K | 商談ログURL |
| L | 送信日時 |
| M | GmailメッセージID |
| N | エラー内容 |

最終行の次から順に追記する。

**4. 二重登録を防ぐ**

追記の前に、シートの **D列（送信先）** に既にあるアドレスを読み込み、
**同じアドレスの行はスキップする。**
同じCSVが誤って置き直されても、二重に入らないようにするため。

**5. 読み終えたCSVを移動する**

キューフォルダの下に `処理済み` というサブフォルダを作り（無ければ作成）、
取り込み済みのCSVをそこへ移動する。次回以降に再読み込みしないため。

**6. 結果を報告する**

Slack の `#チーム浦嶋-aiセールスch`（channel_id: `C094LNTDYGG`）に1回だけ投稿：

```
📋 送信mailログ 追記完了
追記: ◯行 ／ 重複スキップ: ◯行 ／ 取り込んだファイル: ◯件
```

エラーで追記できなかった場合は、何がどう失敗したかを具体的に投稿してください。

### 注意

- **CSVの中身を編集・要約・整形しないこと。** そのままシートに入れる。
- H列の本文には改行が含まれる。1社分が複数行に分かれないよう、セル内改行として扱う。
- CSVの文字コードは UTF-8（BOM付きの場合あり）。
- 列数が14でない行があれば、その行は追記せずエラーとして報告する。
