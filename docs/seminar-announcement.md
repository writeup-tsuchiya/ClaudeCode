# 新セミナー案内文面（過去セミナー視聴者向け）

過去に旧セミナーを見てもらった方へ、内容を刷新した「AI活用セミナー」を案内するためのメール文面。
`{{ }}` は差し込み項目。送付前に必ず全て埋めること（未置換の `{{` が残っていないか検索でチェック）。

---

## 件名案

1. 【内容を刷新しました】{{旧セミナー名}}が「{{新セミナー名}}」として生まれ変わりました
2. 以前ご視聴いただいた{{旧セミナー名}}が、AI活用の内容に変わりました（{{開催日時}}開催）
3. 【ご案内】{{新セミナー名}} / {{開催日時}}・{{参加費}}
4. {{視聴時期}}にご視聴いただいた皆さまへ｜新セミナーのご案内
5. 「AIは結局どう使うのか」をお話しします｜{{新セミナー名}}

> 1・2は「以前見た人」であることを件名で示すので開封率が取りやすい。
> 初回配信は2を推奨、未開封者への再送は5のように切り口を変えると反応が拾える。

## 送付時の注意

- **BCC送信は避ける。** 「以前ご視聴いただいた方へ」という個別性が売りの文面なので、宛先ごとに1通ずつ送る。一斉配信になる場合は差し込み配信機能を使う。
- **旧セミナー名は正確に。** 名前が違うと「見ていない」と判断され、そこで読むのをやめられる。
- **変更点は3つまで。** 増やすほど「結局どこが変わったか」が伝わらなくなる。
- **申込URLは1つだけ置く。** 複数導線があると申込率が落ちる。
- 未開封者への再送は初回から**4〜5日後**、件名を変えて1回まで。それ以上は追わない。
