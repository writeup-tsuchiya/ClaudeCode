# リマインドメール テンプレート

## 共通ルール

- **プレーンテキストで書く**（`body` のみ使用。`htmlBody` は使わない）。装飾より確実に読まれることを優先する。
- 件名は必ず **日時を含める**。受信箱の一覧だけで用件が完結するようにするため。
- `{ }` は description から取れた値で置換する。**取れなかった値は行ごと落とす**（「業種：不明」のような行を顧客に見せない）。
- 「ご返信は不要です／変更が必要なときだけご連絡ください」を必ず入れる。返信対応の工数を増やさないため。
- 当日の流れを3行で書く。**何をされるか分からない不安がドタキャンの主因**なので、ここを省略しない。

## 署名（全テンプレート共通）

```
─────────────────────
株式会社ライトアップ　第一営業部
担当：{担当営業名}
{senderAccount.address}
※本メールは部の共通アドレスから配信しています。
　このままご返信いただければ担当{担当営業名}に届きます。
─────────────────────
```

## A. 初回オンライン商談（AI化スタート診断）

**件名**
```
【明日 {M}/{D}（{曜}）{HH:MM}〜】オンライン打ち合わせのご確認／株式会社ライトアップ
```

**本文**
```
{会社名}
{氏名} 様

お世話になっております。
株式会社ライトアップ 第一営業部 {担当営業名} です。

明日のお打ち合わせのご確認でご連絡いたしました。

■日時
　{YYYY}年{M}月{D}日（{曜}）{HH:MM} 〜 {HH:MM}（{所要}分）

■参加URL（お時間になりましたらこちらから）
　{MeetURL}
　※事前のアプリインストールは不要です。ブラウザでそのまま開けます。

■当日の流れ
　1. 御社の現状と、いま一番お時間を取られている業務のヒアリング（15分程度）
　2. 同じ業種・規模の会社でのAI活用事例のご紹介（15分程度）
　3. 御社で始めるとしたらどこからか、のご相談（15分程度）

　資料のご準備やお申し込みは不要です。お話を伺うところから始めさせてください。

{課題行}

ご都合が変わられた場合のみ、本メールへご返信ください。
日程は改めて調整させていただきます。
問題なければご返信は不要です。

明日はどうぞよろしくお願いいたします。

{署名}
```

`{課題行}` は `お忙しい業務/AI化したい業務` が取れたときだけ、以下を挿入する（取れなければ空行ごと省く）：

```
お申し込み時に「{課題}」とお聞きしております。
この点を中心にお話しできればと考えております。
```

## B. 2回目以降の商談

件名・構成はAと同じだが、**「当日の流れ」を前回の続きとして書く**。

```
■当日の流れ
　1. 前回のお打ち合わせを踏まえたご提案のご説明
　2. 費用・進め方・スケジュールのご確認
　3. ご不明点の整理

　前回いただいたご質問への回答もご用意しております。
```

前回内容が description に無い場合は推測で書かない。上記の汎用表現のままにする。

## C. 来社・訪問

URLの代わりに場所と当日の連絡先を出す。**訪問の場合は先方の住所を勝手に書かない**（誤りが致命的なため、「お伺いいたします」に留める）。

**件名**
```
【明日 {M}/{D}（{曜}）{HH:MM}〜】お打ち合わせのご確認／株式会社ライトアップ
```

**本文の該当部分（来社の場合）**
```
■場所
　株式会社ライトアップ
　当日は受付にて「第一営業部 {担当営業名}」とお伝えください。

■当日ご連絡が必要な場合
　{senderAccount.address} まで、または本メールへご返信ください。
```

**本文の該当部分（こちらから訪問する場合）**
```
■場所
　御社へお伺いいたします。{HH:MM} に到着予定です。

■当日ご連絡が必要な場合
　{senderAccount.address} まで、または本メールへご返信ください。
```

## D. 既存顧客MTG（キックオフ／オンボーディング／納品）

すでに取引がある相手なので、営業色を落として事務連絡のトーンにする。

```
{会社名}
{氏名} 様

いつもお世話になっております。
株式会社ライトアップ {担当営業名} です。

明日のお打ち合わせのご確認です。

■日時
　{YYYY}年{M}月{D}日（{曜}）{HH:MM} 〜 {HH:MM}

■参加URL
　{MeetURL}

■当日の内容
　{商談名から起こした内容を1〜2行。分からなければ「前回の続きのお打ち合わせ」とだけ書く}

ご都合が変わられた場合のみご返信ください。
明日もよろしくお願いいたします。

{署名}
```

## E. その他（種別が判定できないとき）

Aから「当日の流れ」を落とした最小構成にする。日時・URL・変更導線の3点だけを確実に伝える。
**内容が分からないまま流れを書くと事実と食い違うため、書かない方が安全。**
