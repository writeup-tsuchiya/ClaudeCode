# 完成例：株式会社COH（https://www.info-coh.com/）

足立区のロケ弁・会議弁当の製造配達会社。副次事業に仕込み代行・OEM、ご当地弁当。
公式サイトが取得できなかったため、会社情報サイト・プレスリリース・求人票から事実を集めた例。

## 欄ごとの判断メモ（この例から学ぶこと）

- サービス名：「ロケ弁当」（社内表記）ではなく「ロケ弁」（AIがよく使う）。「仕出し弁当」はAIが最も使う一般名なので追加
- 地域：当初「足立区」を入れていたが、ロケ弁は撮影地で探されるため「首都圏」に差し替え
- 競合：当初は推測で「ごちクル」等を入れていたが、「東京 ロケ弁 おすすめ」で実際に挙がるCHAKAS・SOMY'S DELI・くるめし弁当に入れ替え。仕込み代行の大手シコメルフードテックを追加
- 強み：「1,000社以上」「ヴィーガン」「船橋拠点」は確認が取れなかったため「○」と削除候補に回した
- 営業マンのSNS企画（「早朝の仕込み」「1分遅れられない現場」「総務担当者の困った」）から、感情ではなく事実（納品時刻確認・数量チェック・部署別仕分け・請求書一括）を抜いて強み欄と課題欄に入れた

## COHへの確認シート（この順で聞くと⑥が上から埋まります）

```
1. 取引社数：○社以上
2. 仕込み開始時刻：朝○時
3. 1日の最大製造数：○食
4. 自社配送車の台数：○台
5. 最早納品時刻：○時
6. 最小注文数：○個
7. 翌日配達の受付締切：前日○時
8. 当日の人数増減の締切：当日○時
9. 部署別仕分け・請求書一括発行：有／無
10. 仕込み代行の発注リードタイム：○日前
11. ヴィーガン対応：有／無
```

- 9が無 →「手配する担当者の数量ミスや〜一括発行も行っています。」の文を削除
- 11が無 →「ヴィーガン弁当にも対応可能です。」の文を削除

## 貼り付け前の注意

- ①③は読点「、」区切り、④⑦は改行区切り。スペース区切りにしない
- ③にURLを入れない
- ④⑤に「わかりません」「わかりました」を入れない
- 計測対象（契約時に確定）が何になっているか先に確認。ロケ弁以外なら①の並び順と⑦の比率を寄せ直す

## 設定直後にやること

自動生成された50問を確認し、次が含まれていたら事務局に差し替えを依頼する。

- 社名入りの質問（「株式会社COHの事業内容は？」など）
- 「飲食店会社」「弁当会社」のような不自然な言い回し
- 地域とサービスが噛み合わない質問（「千葉で弁当OEMに強い会社は？」など）
