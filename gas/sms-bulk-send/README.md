# 📱 SMS一括配信（ボタン起動）

スプレッドシートに **名前と電話番号を書いて、ボタンを押した瞬間に一括送信**するGAS。
時間トリガーは使いません（押したときだけ動く）。本文は「SMSテンプレート」シートから読み込みます。

```
送信リスト（名前・電話番号）        ┐
SMSテンプレート（本文）             ├─▶ [一括配信ボタン] ─▶ 確認ダイアログ ─▶ SMS送信 ─▶ 結果を行に書き戻し＋ログ
システム設定（トークン等）          ┘
```

## 1. セットアップ

1. スプレッドシートを開き、**拡張機能 → Apps Script**
2. `Code.gs` の中身を貼り付けて保存（ファイル名は何でもOK）
3. エディタ上部の関数選択で `initSheets` を選び ▶ 実行 → 権限を承認
   → `送信リスト` `SMSテンプレート` `システム設定` `SMS送信ログ` が作られます
4. スプレッドシートを開き直すと、メニューに **📱 SMS一括配信** が出ます

`appsscript.json` は同梱の内容に合わせておくと、必要な権限が最小構成になります。

## 2. シートの作り方

### システム設定

| 項目 | 値 |
|---|---|
| トークン | （SMS APIのtoken） |
| クライアントID | （clientId） |
| SMSコード | （smsCode） |
| 既定テンプレート | セミナー案内 |

> 既存の「システム設定」シート（B4=token / C4=clientId / D4=smsCode の旧レイアウト）もそのまま読めます。

### SMSテンプレート

| テンプレート名 | メモ | 本文 |
|---|---|---|
| セミナー案内 | 一斉案内用 | `{{名前}}様`<br>`本日のセミナーのご案内です。` |
| リマインド | 前日用 | `{{姓}}様 明日はよろしくお願いいたします。` |

**差し込みタグ** — `{{ }}` の中に**送信リストのヘッダー名**をそのまま書けます。

| 書き方 | 入るもの |
|---|---|
| `{{名前}}` `{{お名前}}` `{{ご担当者名}}` | 姓＋名（または「お名前」列の値） |
| `{{姓}}` / `{{名}}` | 姓 / 名 |
| `{{会社名}}` `{{担当}}` など | 送信リストに同名の列があればその行の値 |

未定義のタグは空文字になります（`{{ }}` がそのまま送信されることはありません）。本文は660文字で切ります。

### 送信リスト

| 送信対象 | お名前(姓) | お名前(名) | 電話番号 | テンプレート | 送信ステータス | 送信日時 | API応答 |
|---|---|---|---|---|---|---|---|
| ☑ | 山田 | 太郎 | 090-1234-5678 | | | | |
| ☑ | 佐藤 | 花子 | 08011112222 | リマインド | | | |

- **必須は電話番号列だけ**。名前は `お名前(姓)/お名前(名)` でも `お名前` 1列でもOK
- ヘッダーは表記ゆれに強い（全角/半角、`電話` `TEL` `携帯`、`お名前（姓）`/`お名前(姓)` など）
- **送信対象列**：チェックが入った行だけ送信。**列ごと無ければ全行が対象**
- **テンプレート列**：空なら「既定テンプレート」を使用。テンプレートが1件だけなら自動でそれを使用
- 右3列（送信ステータス・送信日時・API応答）は**無ければ自動で追加**されます
- 電話番号は `090-1234-5678` / `09012345678` / `+819012345678` / 全角 いずれもOK。先頭の0落ち（`9012345678`）も救済します

## 3. 送信する

メニュー **📱 SMS一括配信 → ▶ 一括配信を実行**、または後述のボタンを押す。

```
┌─ SMS一括配信の確認 ──────────────┐
│ 12件のSMSを送信します。              │
│  ・エラーでスキップ: 1件             │
│  ・送信済み等でスキップ: 3件         │
│  ・⚠ 電話番号の重複: 1件            │
│ ─ 1件目のプレビュー ─                │
│ 宛先: 山田太郎（+819012345678）      │
│ 山田太郎様 …                         │
│              [ OK ]  [ キャンセル ]  │
└──────────────────────────────────┘
```

OKを押すと送信が始まり、終わったら成功／失敗の件数が出ます。

### ボタンを作る（シート上の図形に割り当て）

1. **挿入 → 図形描画** で四角を描き「📱 一括配信」と入力 → 保存して閉じる
2. 図形の右上「⋮」→ **スクリプトを割り当て**
3. `sendBulkSms` と入力して OK

以降はその図形を押すだけで配信できます。

## 4. メニューの各項目

| メニュー | 何をするか |
|---|---|
| ▶ 一括配信を実行 | 確認ダイアログ → 一括送信（`sendBulkSms`） |
| 👀 本文プレビュー | **送信せず**、対象件数と先頭3件の本文を表示 |
| ✉ テスト送信（1件だけ） | 番号とテンプレートを指定して自分宛に1通 |
| 🔍 設定チェック | シート・トークン・列の判定結果を一覧表示 |
| 🧹 送信ステータスをクリア | 結果3列を空に（＝全行が再送対象に戻る） |
| 🛠 シートを初期化 | 必要なシートを作成（初回のみ） |

## 5. 安全装置

| リスク | 対策 |
|---|---|
| ボタン連打・二重送信 | `LockService` で二重起動を防止 |
| 意図しない全件送信 | 送信前に件数＋1件目の本文プレビューで確認 |
| 押し間違いによる再送 | 「送信成功」の行は再実行しても**必ずスキップ**。失敗行だけ再送される |
| 途中で止まった | **1件ごとに**シートへ書き戻すので、どこまで送ったかが残る |
| GASの6分制限 | 5分で安全停止。未送信件数を表示し、**もう一度押せば続きから** |
| 設定ミスで無駄打ち | トークン・テンプレート未設定なら**1件も送らずに**中止 |
| 番号の重複 | 確認ダイアログに重複件数を表示 |

送信結果はすべて `SMS送信ログ` シートに残ります（日時／行番号／宛名／入力番号／送信先番号／テンプレート／ステータス／本文／API応答）。

## 6. 元のリマインダー版との違い

| | 元のGAS | このGAS |
|---|---|---|
| 起動 | 時間トリガー（±30分の窓で自動送信） | **ボタン** |
| 対象の決め方 | セミナー日時からの相対時間（24h前など） | **送信対象チェック＋電話番号の記入** |
| テンプレート選択 | タイミングのラベルで自動選択 | **既定テンプレート or 行ごとの指定** |
| 差し込み | `{{ご担当者名}}` `{{姓}}` のみ | **任意のヘッダー名を `{{ }}` で差し込み可能** |
| 実行確認 | なし（自動） | **件数＋本文プレビューの確認ダイアログ** |
