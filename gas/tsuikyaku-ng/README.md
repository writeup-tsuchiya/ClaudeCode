# 追客NG 自動判定（GAS）

精査元スプレッドシートの **C列の名称** が対象リストに一致したら、その行の **G列のプルダウンを「追客NG」** に書き換えるGoogle Apps Script。

- 対象ブック: `1li2epxdbOUk87DuHgg9NKgQAize__EUp8-E5BogqtWI`
- 対象シート: `gid=1403156942`
- 判定対象の名称: 尼崎信用金庫 / 株式会社肥後銀行 / 埼玉りそな銀行 / りそなグループ / 東京海上日動火災保険株式会社 / 港区 / 宇都宮市

## 導入手順

1. 対象スプレッドシートを開き、**拡張機能 → Apps Script**。
2. `Code.gs` の中身をまるごと貼り付けて保存。
3. エディタ上部の関数リストから `applyTsuikyakuNg` を選んで **実行**。初回だけ権限承認が出るので許可する。
4. シートを開き直すと、メニューバーに **「追客NG判定」** が出る。以降はそこから実行できる。

## できること

| メニュー / 関数 | 動作 |
|---|---|
| `applyTsuikyakuNg` | シート全体を精査して、該当行のG列を「追客NG」に一括更新 |
| `previewTsuikyakuNg` | **書き換えずに**、対象になる行と現在のG列の値をログ出力（ドライラン） |
| `onEdit` | C列を手入力・貼り付けした瞬間に、その行のG列を自動で「追客NG」に |
| `createOnEditTrigger` | 簡易トリガーが効かない場合（保護シート等）用のインストーラブルトリガー設置 |

**まず `previewTsuikyakuNg` で対象行を確認してから `applyTsuikyakuNg` を実行することを推奨します。**
実行ログは Apps Script エディタの「実行数」→ 該当実行、または `Ctrl+Enter` のログで確認できます。

## 設定（`CONFIG`）

| 項目 | 既定値 | 説明 |
|---|---|---|
| `spreadsheetId` | 上記ID | 空文字にすると「開いているブック」を対象にする |
| `sheetGid` | `1403156942` | 対象シート。URLの `#gid=` の数値。名前で指定したい場合は `sheetName` を使う |
| `nameColumn` / `targetColumn` | `3` / `7` | 名称の列（C）／書き換える列（G） |
| `startRow` | `2` | データ開始行。ヘッダーが2行あるなら `3` に |
| `matchMode` | `'normalized'` | 一致判定の方式（下記） |
| `overwriteExisting` | `true` | G列に既に別の値があっても上書きする。`false` なら空欄行だけ |
| `autoExtendDropdown` | `false` | プルダウンに「追客NG」が無いとき選択肢に追加するか |

対象名称を増やすときは `NG_NAMES` に1行足すだけです。

### 一致判定の方式

- `'normalized'`（既定・推奨） — 表記ゆれを吸収した完全一致。
  全角/半角、スペース、`・`や`-`などの記号、`株式会社`/`(株)`/`㈱` といった法人格を無視して比較します。
  例: `（株）肥後銀行` `株式会社 肥後銀行` `㈱肥後銀行` `肥後銀行` はすべて `株式会社肥後銀行` と一致。
  `港区役所` `りそな銀行` のような**別の名前は一致しません**。
- `'partial'` — 上記に加えて部分一致も拾う。`港区役所` や `りそなグループ株式会社` も対象にしたい場合に。
  広く拾う分、意図しない行まで「追客NG」にする可能性があるので、必ず `previewTsuikyakuNg` で確認してから使ってください。
- `'exact'` — 文字列そのままの完全一致。リストの表記と1文字でも違えば対象外。

## 注意点

- **G列のプルダウンに「追客NG」の選択肢が無い場合**、値はセットされますが入力規則違反のマーク（セル右上の赤い三角）が付くことがあります。
  ログに警告が出るので、その場合は入力規則に「追客NG」を追加するか、`CONFIG.autoExtendDropdown = true` にして再実行してください。
- すでに `onEdit` が定義されているスクリプトに追記する場合は、既存の `onEdit` の中で `handleEdit_(e)` を呼ぶ形にしてください（`onEdit` は1プロジェクトに1つしか持てません）。
- 一括更新は「変更が必要な行」だけを、連続行はまとめて書き込みます。すでに「追客NG」の行は触りません。
