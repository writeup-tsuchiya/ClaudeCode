# 判例集

失敗と対処の記録。**その理由が効く条件まで書く**こと（§10-7）。

```
× SadTalker は遅いので使わない
⭕ SadTalker は実時間の183倍。10分動画=30時間なので この用途では使わない（尺が短ければ成立しうる）
```

倍率のような線形に効く数字は、**条件を変えたときの再計算に使える資産**になります。
条件を書かずに結論だけ残すと、条件が変わっても却下が引き継がれます。

## 書き方

1件1ファイル。`YYYY-MM-DD-短い題.md`。

```markdown
# 題

**症状**: 何が起きたか
**原因**: 実際の原因（エラーメッセージの主語をそのまま原因にしない・§10-2）
**対処**: どう直したか
**効く条件**: この結論はどこまで有効か
**測った値**: 推測ではなく実測。測っていないなら「測っていない」と書く
```
