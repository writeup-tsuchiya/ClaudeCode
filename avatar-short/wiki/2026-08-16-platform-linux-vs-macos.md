# 構築した環境と、実行する環境が違う — 何を検証したのかを分けて記録する

**状況**: このリポジトリは **Linux x86_64 のリモートコンテナ**で組み立てた。
要件定義書 §3-1 が前提とする **macOS (Apple Silicon)** ではない。

```
                 §3-1 の前提            組み立てた環境
OS               macOS (Apple Silicon)  Linux x86_64
GPU              Apple 内蔵GPU (MPS)    なし
Python           3.10                   3.11（3.10 も併存）
ffmpeg           brew の標準ビルド       static ビルド（drawtext なし・drawbox あり）
```

🔴 **だから「動いた」と「動くはず」を混ぜて書かない。**

## この環境で実際に測って確かめたこと

| 対象 | やったこと |
|---|---|
| 決定論（§10-4b） | `PYTHONHASHSEED` を 0/1/42/12345 に変えて `rotation()` が同一結果を返すことを確認。同条件で `hash()` は 4/4/1/0 と変わった |
| §8-2 のパッチ | 実物の SadTalker に当てて `py_compile` が通ることと、型文字列の翻訳が `torch.mps.FloatTensor → ('mps', float32)` になることを確認 |
| §6-4 の台本検査 | 「！」の検出、全ひらがなの警告、target_sec 超過の警告が出ることを確認 |
| ⑥slides（Manim） | 実際に 1080x1920 / 30fps / 31.467秒 の mp4 を焼き、フレームを目視 |
| ⑦compose | slides + ワイプ + 音声を合成し、1080x1920 / h264+aac を確認 |
| ⑧verify | 静止した素材で口の動き 0.0、動く素材で 4.26 と、両側で反応することを確認。無音区間 221/941 フレームの除外も確認 |
| `run_bg.sh` | 終了コード7が `.exit` ファイルに残ることを確認 |

## この環境では確かめられなかったこと

| 対象 | なぜ |
|---|---|
| ④voice の実際の音声品質 | Irodori-TTS のモデル取得と torch 2.10 環境を作っていない |
| ⑤avatar の実際の生成 | Apple GPU が無い。§8-2 の「17.8倍」も測れない |
| §8-2 パッチ2/3（Conv3D on MPS） | MPS が無いので、新しい torch で本当に動くかは未確認 |
| ③face の RetinaFace 検出 | SadTalker の重み（約2.5GB）を取得していない |
| HyperFrames エンジンのレンダ | Chrome の取得と localhost 接続が要る（§7-6） |

**上の表の右側は、Mac で通したときに `wiki/` に追記してください。**
そのとき、倍率のような線形に効く数字は必ず残すこと（§10-7）。

## この件から引ける教訓

「未検証」と「動かない」は別。
記録に「動かない」と書くと、条件が変わっても引き継がれる（§10-7 と同じ形の失敗）。

⑧verify の `measured: false` も同じ思想で作ってある。
**測っていないことと、動いていないことは別**なので、
`.claude/agents/video-evaluator.md` は `measured: false` を不合格にせず「未測定」と言う。
